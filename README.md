# MLS research starters

This branch contains original weak starting code and the public contract for
`mls_joint-audit-portfolio-7k1440`, a joint-measurement portfolio audit task.
The subdirectory is the complete public code starting point. Development data
and evaluator resources are supplied in the separate proposal package.

The original root `policy.py` belongs to the earlier delayed-drift prototype;
new proposals refer to their named subdirectories at an immutable commit.

These are research candidates. Functional measurements, difficulty studies and
customer acceptance are separate; this repository makes no acceptance or
minimum model-call claim.
